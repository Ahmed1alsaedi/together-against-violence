# معًا ضد العنف ضد المرأة

موقع توعوي عربي تفاعلي للتعرّف على أشكال العنف ضد المرأة وكيفية مساندة من تتعرّض له.

[افتح الموقع على GitHub Pages](https://ahmed1alsaedi.github.io/together-against-violence/)

## داخل الموقع

- **جولة سريعة** تجمع ثلاثة أسئلة من ألعاب مختلفة.
- **وين المشكلة؟** تختار العبارة التي تدل على المشكلة داخل موقف قصير، ثم يظهر شرحها.
- **الخدمة الاجتماعية** توضّح دور الأخصائية الاجتماعية مع مثال وزر للوصول إلى صفحة الدعم.
- **تعلّم** يقدم معلومات قصيرة مع أمثلة عملية.
- **بطاقة التزامي** تتيح إنشاء بطاقة توعوية وتحميلها بصيغة PNG.
- **أين أجد الدعم؟** تعرض أرقام التواصل في السعودية ورابط مركز بلاغات العنف الأسري.

## التشغيل والنشر

افتح ملف `index.html` في المتصفح. الموقع يعمل بملف HTML واحد ويحتوي الملف على التصميم والألعاب.

لنشره من GitHub Pages، ارفع الملفين إلى جذر فرع `main`، ثم من إعدادات المستودع اختر **Pages**، وحدد **Deploy from a branch** والفرع `main` والمجلد `/ (root)`.
